## 一文で言うと

**薬剤が、がん細胞表面の糖鎖エピトープの「標的性・検出性」をどう書き換えるかを、
LINCS薬剤応答から定量し、どのエピトープが薬で操作できるかを判定する基準を作って、
レクチンで実証する。**

治す薬を探すのではない。**「腫瘍を抗体・レクチンで狙いやすく／見つけやすく変える薬」を見つける**、
という一段手前の・でも創薬に直結する主張。

## 薬でエピトープが変わると、なぜ創薬に繋がるのか

糖鎖エピトープは、抗体・レクチン・免疫受容体（Siglec）・接着分子（セレクチン）・galectin といった
認識分子が、がん細胞を認識するために実際に触れる **細胞表面のインターフェース** である。
だからエピトープが変われば、その細胞が「どれだけ検出できるか」「どれだけ狙えるか」が同時に変わる。

- **検出**：薬がエピトープを動かせば、それはレクチン/抗体で測れる薬力学（PD）マーカーになる。
  core fucose の増加が AFP-L3 として測れるのはその実例。
- **標的化**：エピトープはそのまま抗体・ADC・CAR-T の標的密度である。薬がそれを増やすなら、
  標的療法の **感作剤**——「先に標的を濃くしてから叩く」併用——になりうる。
- **抑制**：STn・sialyl Lewis・poly-LacNAc のような免疫回避・転移を担うエピトープを薬が下げるなら、
  その薬に糖鎖機構的な抗腫瘍の根拠が立つ。

治療効果そのものを主張する手前で、**標的性そのものを設計対象にする**——それが核心である。

## 埋める空白

「発現から糖鎖構造を推す」枠組みは既に2方向から埋まっている。**どちらも摂動を入れていない（静的）**のが共通点：

| 軸 | 先行研究 | 到達点 |
|---|---|---|
| 静的・細胞側 | GlycoMaple (Huang 2021), Kawano 2005 | 発現プロファイル→糖鎖構造の予測 |
| 静的・**疾患**側 | **Akiyoshi, Iwata, Berenger, Yamanishi. *Mol Inf* 2020** | CREEDS 79疾患×glycogene 332→13経路のfilling rate→疾患-疾患マップ |
| **動的・薬剤側** | **← 空白。ここが3rd paper** | 薬剤誘導のエピトープ変化を定量し、標的性・検出性に接続 |

> **Akiyoshi 2020 との関係（2026-08-02 に整理）**：山西先生は指導教員であり、体制は共同研究
> （dry は著者、wet は山西研側）。Akiyoshi 2020 は**同じ研究室の既発表**なので、
> Introduction で引用して土台にする。
>
> **手法やデータが被ること自体は問題ではない。問いが違うため。**
> Akiyoshi 2020 の問いは「どの疾患同士が糖鎖的に似ているか」（静的・疾患間、薬剤は1化合物も出てこない）、
> 本研究の問いは「**どのエピトープが薬で操作でき、検出・標的にできるか**」（動的・薬剤軸）。
> 加えて表現の分解能が違う——あちらは 13 の KEGG 経路の filling rate（符号なし・カウントベース）、
> こちらはエピトープ単位で方向を持ち、認識分子まで繋ぐ。
> 研究室の蓄積の上に別の問いを立てるのは、共同研究として正常な形である。

## 論文の型：判定型

| 型 | 判定 |
|---|---|
| 予測型（当てる・精度） | ✗ 2026-07-25に放棄。AUC 0.63級の天井があり、研究室自身が精度勝負から降りている |
| 記述型（地図を描く） | ✗ 死んだ作業の大半。Akiyoshi 2020 と衝突する |
| **判定型（基準を作り1例で実証）** | **◎ ここに収束した** |

判定型の中身は「**どのエピトープが薬で操作できるか**」の基準を提示すること：

1. **druggability** — そのエピトープを検出閾値以上動かす薬が何本あるか（絶対量。順位ではない）
2. **targetability** — 認識分子が何個あるか、アッセイで使えるか、買えるか
3. **構造的な規則** — アイソ酵素の**冗長性が低いエピトープほど薬剤で操作しやすい**
   （多遺伝子エピトープは全アイソ酵素を同時に抑えないと動かないため。`docs/wet_target_selection.md`）

**予測でも網羅でもないので、シグナルが弱くても成立する。** これが弱いシグナルへの回答である。

## 主張の鎖（3層）

```
層B 薬剤   LINCS絶対量 → エピトープ量の変化 → 閾値を越える薬     【厚い】
層A 辞書   エピトープ → 生合成遺伝子(済) → 認識分子(未)          【半分】
層C 検証   wet: HepG2 + レクチン                                【未着手】
```

> **薬がエピトープを動かす（B）→ 認識分子で見える・狙える（A）→ 実際に糖鎖が動く（C）**

各リンクは証拠の種類が違い（計算／文献・DB／実験）、**論文の強さは最弱リンクで決まる。**
現状 厚いのは層Bだけ。詳細は `docs/roadmap_to_thesis.md`。

## 体制と役割分担

**共同研究。dry は著者（在野研究者）、wet は山西研側に依頼する。**
著者が持ち込むのは **dry の実装と糖鎖の専門知識**——エピトープ辞書、認識分子との対応、
どのレクチン・抗体が何を読むか、どの構造が臨床でどう使われているか。ここは研究室に無い層である。
研究室から借りるのは LINCS の手法資産（細胞内マッチング＝Iwata 2017、経路スコア＋wet検証＝Iwata 2018）と wet。

wet を依頼する以上、**dry が「試す価値がある」と思わせる出来である必要がある**
（依頼の設計は `docs/roadmap_to_thesis.md` Phase 2）。

## この研究だからできること

1. **薬剤誘導**（静的予測でなく「薬でどう動くか」）
2. **エピトープ単位のスコア**（遺伝子でなく標的性の単位）→ 抗体/レクチン文脈に直結
3. **正常対照**：PHH は LINCS 最良の正常肝対照（乳の MCF10A は薬剤数が少ない）。
   HepG2 vs PHH で既知生物学が再現済み（FUT8 +1.76 / MGAT5 +2.48 / UGT群は正常肝優位）
4. **wet に届く距離**：HepG2 + レクチン染色は最小構成（1細胞株・2〜3剤・数日規模）で、依頼として通りやすい

## 何がデータで裏付けられているか（2026-08-02時点）

| 主張 | 根拠 |
|---|---|
| 糖鎖表面は細胞アイデンティティでほぼ決まる | 絶対量PCAで細胞株が分散の63.7%、薬剤は実質6.3%（24h/10uM, 13,212組） |

## 正直な線引き

- **主張する**：薬が糖鎖インターフェース（標的性・検出性）を再配線しうる。どのエピトープが操作可能かを判定できる。
- **主張しない**：薬が腫瘍を治す（直接の治療効果）。母集団レベルの統計的優位。
- **発現 ≠ エピトープ量**：酵素の局在（GALA）・翻訳後制御で乖離する。**これを確かめるのが wet の役目。**
- **測定区分の限界**：辞書57遺伝子のうち L1000 landmark は3個のみ（EXT1, FUT1, ST3GAL5）、
  BING 37、plain inferred 6、L1000外 11。**MGAT5 は plain inferred、ST6GALNAC1(STn) は L1000 に無い**
  （`docs/lincs_data_inventory.md` §4.2）。
  ※ ただし plain inferred が系統的に振れやすいわけではない（HEPG2 での sd 中央値は
  inferred 0.317 < BING 0.381 < landmark 0.507）。MGAT5 の大きな応答は区分の副産物ではなく
  クラス内の外れ値である（2026-08-02 検証）。
- **母集団統計は立たない**：薬剤寄与が実質6.3%と弱く、47エピトープ中31が1遺伝子。
  **「N個集めて有意差」の形の主張は原理的に成立しない**（`docs/set_based_aggregation_feasibility.md`）。

## 迷ったときの判定基準

新しい解析・図を足すか迷ったら：

1. **形を見る。**「N個集めて有意差」ならおそらく死ぬ。「この薬がこのエピトープをこれだけ動かす」なら生きる。
2. **層を見る。** 層B（薬剤）を厚くする案は、もう限界効用が低い。層A（認識分子）と層C（wet）に効くか。
3. **単位を見る。** 遺伝子の話になっていないか。エピトープ単位を保っているか。
