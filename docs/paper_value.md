## 薬でエピトープが変わると、なぜ薬理・創薬に繋がるのか（名文）

糖鎖エピトープは、抗体・レクチン・免疫受容体（Siglec）・接着分子（セレクチン）・galectin といった「読み手」が、がん細胞を認識するために実際に触れる **細胞表面のインターフェース** である。だからエピトープが変われば、その細胞が「どれだけ検出できるか」「どれだけ狙えるか」「どう振る舞うか」が同時に変わる。

薬剤は糖鎖合成酵素の遺伝子発現を動かすことで、このインターフェースを書き換えられる。ここに薬理・創薬への回路が開く：

- **検出**：薬がエピトープを増やせば、それはレクチン/抗体で測れる薬力学（PD）マーカーになる。core fucose の増加が AFP-L3 として測れるのはその実例で、薬が効いたことを非侵襲に読み出せる。
- **標的化**：エピトープはそのまま抗体・ADC・CAR-T の標的密度である。薬がそれを増やすなら、標的療法の **感作剤**——「先に標的を濃くしてから叩く」併用——になりうる。
- **発見**：あるエピトープを疾患シグネチャ横断で評価すれば、そのエピトープを **どの疾患で標的にすべきか（下げるべき/上げるべき）** が見える（山西研の target repositioning 枠をエピトープに応用）。
- **抑制**：STn・sialyl Lewis・poly-LacNAc のような免疫回避・転移を担うエピトープを薬が下げるなら、その薬に糖鎖機構的な抗腫瘍の根拠が立つ。

つまり「薬でエピトープが変わる」という一見地味な現象は、**腫瘍の"見つけやすさ・狙いやすさ・振る舞い"を薬で操作できる** という、検出・標的・発見・抑制の四つの創薬回路に直結している。治療効果そのものを主張する手前で、**標的性そのものを設計対象にする**——それがこの繋がりの核心である。

## 一文で言うと

**「薬剤が、がん細胞表面の糖鎖エピトープの"標的性・検出性"をどう書き換えるか」を、
LINCS薬剤応答から全薬剤×全エピトープで初めて定量し、
がん種を跨いで「同じ糖鎖状態を作る薬」の対応表に落とす。**

治す薬を探すのではない。**「腫瘍を抗体・レクチンで狙いやすく／見つけやすく変える薬」を見つける**、という一段手前の・でも創薬に直結する主張。

さらに一段具体化すると：**乳がんで palbociclib が作る糖鎖表面と、肺で crizotinib が作る糖鎖表面が同じなら、その糖鎖を狙う手段（レクチン検出・抗体・ADC）は系統を越えて転用できる。** 各系統の適応承認薬を「旗」として立て、その近傍に落ちた他系統の薬が転用候補になる。

## 埋める空白（なぜ今までに無いか）

- 糖鎖エピトープは **抗体・レクチン・Siglec・セレクチン・galectin が実際に触る細胞表面の接点**。ここが変われば「検出できるか・狙えるか・がんの振る舞い」が全部変わる。
- 「発現から糖鎖構造を推す」枠組み自体は既に2方向から埋まっている。**どちらも摂動を入れていない（静的）**のが共通点：

  | 軸 | 先行研究 | 到達点 |
  |---|---|---|
  | 静的・細胞側 | GlycoMaple (Huang 2021), Kawano 2005 等 | 発現プロファイル→糖鎖構造の予測 |
  | 静的・**疾患**側 | **Akiyoshi, Iwata, Berenger, Yamanishi. *Mol Inf* 2020** | CREEDS 79疾患×glycogene 332→13経路のfilling rate→疾患-疾患マップ（PCA/GTM）、疾患特異的糖鎖バイオマーカー候補 |
  | **動的・薬剤側** | **← 空白。ここが3rd paper** | 薬剤誘導のエピトープ変化を全薬剤網羅で定量し、標的性・検出性に接続 |

- **「薬剤で誘導される変化」を、エピトープ量として全薬剤網羅で定量し、標的性・創薬に接続した仕事は無い。** ここが新規性。
- ⚠ **Akiyoshi 2020は最近接の先行研究**（かつ山西研＝共同研究相手候補）。Introductionで必ず引用し、**薬剤軸で線を引く**こと。引用せずに出す方が危険で、引用すれば土台になる。彼らの論文には薬剤が1化合物も出てこず、認識分子レイヤーもwetも無い。かぶるのはFig4の疾患横断マップ部分のみ（詳細 `inputs/papers/README.md`）。

## 創薬・薬理への4つの出口（価値の本体）

```
薬 → glycogene発現変化 → glyco-epitope potential 変化
                          ├─ 検出できる → バイオマーカー/PD/コンパニオン診断
                          ├─ 狙える    → 抗体/ADC/CAR-T との併用・感作（標的密度を上げてから叩く）
                          ├─ 系統横断で転用 → アンカー（適応承認薬）近傍の他系統薬＝転用候補
                          └─ 振る舞い変化 → STn/sialyl Lewis/poly-LacNAc を下げる＝免疫回避・転移の抑制根拠
```

**一番刺さる出口**：出口2（併用・感作）＋出口1（PDバイオマーカー）。

出口1の臨床的実体は系統ごとに揃っており、**HCC専有ではない**：

| 系統 | エピトープ | 臨床での実体 | 辞書 |
|---|---|---|---|
| 肝 | core fucose | **AFP-L3**（承認バイオマーカー） | ○ |
| 大腸・膵 | Sialyl Lewis a | **CA19-9**（承認バイオマーカー） | ○ EP0008 |
| 乳・卵巣 | Globo-H | adagloxad simolenin（第3相ワクチン） | ○ |
| 乳 | Sialyl Tn | Theratope（STnワクチン） | ○ EP0022 |
| メラノーマ | GD2 / GD3 | 抗GD2抗体の系譜 | ○ EP0061 等 |

## この研究だからできること

1. **薬剤誘導**（静的予測でなく「薬でどう動くか」）
2. **全薬剤網羅**（LINCS）→ リポジショニングが言える
3. **エピトープ単位のスコア**（遺伝子でなく標的性の単位）→ 抗体/レクチン文脈に直結
4. **同一薬剤セット × 複数細胞という内部対照**：LINCSはtouchstone設計なので、同じ承認薬約400が各細胞株に一通り撒かれている（A549∩HEPG2=402、HCC515∩HEPG2=385、HUH7∩HEPG2=191、PHH∩HEPG2=262）。
   **※2026-07-30 訂正**：これらはLevel 5（z-score・全条件込み）の数字。条件を揃えた絶対量では
   **PHH∩HEPG2=76薬**（24h/10uM）、HUH7は条件一致で12薬のみ（本体は72h）。この内部対照の設計自体、
   絶対量では細胞株が分散の63.7%を占めるため「同一薬ペアの距離」が細胞差にほぼ支配される（上のブロック参照）。**同一薬ペアの距離分布が「細胞コンテキストだけで動く量」の物差し**になり、`d(薬X@乳, 薬Y@肺) < d(薬X@乳, 薬X@肺)` という形で「近い」を主観的閾値でなく内部基準で判定できる
5. **二層アンカー**（2026-07-28決定）→ 「近い」の主張が2段階の検定になる：

   | 層 | 中身 | 役割 |
   |---|---|---|
   | **Tier 2（背景）** | がん適応の承認薬 **59**／細胞（HEPG2 59, A549 58, MCF7 58, PC3 58, A375 57, HT29 57, VCAP 56, HCC515 55, **PHH 30, HUH7 28**） | 臨床で使われる抗腫瘍薬がエピトープ空間で占める**雲**。59本あるので分布として検定できる（Mahalanobis/z） |
   | **Tier 1（旗）** | 系統一致 **16** | 「その系統の薬はここに落ちる」。転用の主張を担う |

   判定は **①雲の中か（抗腫瘍薬らしい振る舞いか）かつ ②雲全体より系統一致16本に有意に近いか**。①だけでは弱いが、①かつ②なら「その系統の薬に特異的に似ている」になる。**Tier 2を旗でなく背景に回すことで、旗を増やしたときの特異性低下が消える。**
   転用候補の母集団は **402 − 59 = 343本の非がん承認薬**。
6. **HCCの深掘り**（core fucose/AFP-L3、PHHという最良の正常対照）→ wet validation（HepG2 + AALレクチン）まで最短

## 正直な線引き（過剰主張しない）

- **主張する**：薬が糖鎖インターフェース（標的性・検出性）を再配線しうる。
- **主張しない**：薬が腫瘍を治す（直接の治療効果）。
- 既知の限界：**発現≠エピトープ量**（酵素の局在GALA・翻訳後制御で乖離）。transcriptomeシグナルは弱く、コントラスト対比や経路構造（step内max×step間min, 分岐競合）で分離を作る必要がある。
  → だからこそ「素朴な和でなく、生合成経路を反映したスコア」に価値がある。
- **エピトープ遺伝子はほぼ実測されていない**：辞書の57遺伝子のうちL1000ランドマークは **3個のみ（EXT1, FUT1, ST3GAL5）**、残り54は推論値。距離を論じる解析では「近さが推論モデルの低ランク構造の副産物でないか」を必ず対照で潰す（同サイズのランダム推論遺伝子セット、およびランドマーク空間の距離との比較）。
- **細胞株≠疾患**：1株の癖でないことを、肝は HEPG2/HUH7/PHH の共通127薬、肺は A549/HCC515 の共通385薬で確認する。
- LINCSに**レンバチニブ・カボザンチニブが無い**（HCC第一選択級）。HCC深掘りパートで先に認める限界。

## 迷ったときの判定基準

新しい解析・図を足すか迷ったら、**「これは4つの出口のどれを強めるか？」**で判断する。
どの出口にも効かないなら、それは論文の価値には効いていない。
