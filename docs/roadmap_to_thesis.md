## 収束点：レクチンで実測した「薬でエピトープが動く」1事例

3つの要求それぞれを、それ単独で見たときに何が足りないかを並べる。

| 要求 | 今のままだと言われること | 埋めるもの |
|---|---|---|
| **創薬的価値** | 「推論値の遺伝子発現から糖鎖を推測しただけ。糖鎖は測っていない」 | 糖鎖の実測 |
| **山西先生** | 「Akiyoshi 2020 と Iwata 2018 の延長線上で、君が足したのはどこ？」 | 研究室に無い層 |
| **博論** | 「1st・2nd と同じ測定量（遺伝子発現）の3回目」 | 測定量の変化 |

**3つとも同じもので埋まる。** HepG2 に候補薬をかけ、AAL/LCA レクチンで core fucose が予測通り動くことを示した1事例——
これが無いと3つとも立たず、あれば3つとも立つ。だから優先順位は迷う余地がない。

### なぜ dry を積み増しても埋まらないか

研究室の到達点を正確に把握しておく（`inputs/papers/README.md`）。**これは敵情視察ではなく、
「どこまでが既に自分の研究室の資産で、どこから先が自分の仕事か」の線引きである。**

- **Iwata 2018, J Med Chem**：1,112薬 × 66細胞株。経路構造スコアで薬を選び、**in vitro 3アッセイ（生存率・細胞毒性・アポトーシス）で実験検証**。
  → 「経路スコア＋wet検証」という本プロジェクトの図構成の、**ほぼ完成形の先例**が既にある。
- **Iwata 2017, Sci Rep**：同一細胞株マッチングが別細胞株より大幅に優ると報告。
  → 交差細胞が転移しないことは**2017年に文書化済み**。こちらが7/29に潰した設計は、彼らが9年前に回避していた。
- **Akiyoshi 2020, Mol Inf**：CREEDS 79疾患 × glycogene 332 → 13経路の filling rate → 疾患-疾患の糖鎖マップ。
- **Akiyoshi は糖鎖論文と LINCS 論文の両方の著者**。同じ研究室内で「糖鎖×CREEDS」と「薬剤×LINCS」の
  両方に関わった人が既にいる。**こちらがやろうとしていることの前例と失敗を最もよく知っている人**である。

つまり **dry を積み増しても、研究室が既に持っている層の上塗りにしかならない。**
手法資産も経験もラボの側が厚く、Akiyoshi は糖鎖と LINCS の両方を知っている。
そこで新規性を主張すると、**指導教員から見て一番弱く見える場所で勝負する**ことになる。

**研究室に無いのは糖鎖を実測する層である。** ラボの wet は細胞死アッセイまでで、
レクチンで細胞表面を読む発想も設備も論文も無い。そしてこちらは 1st paper から糖鎖生物学をやってきた人間である。
**ここが、研究室の蓄積に自分だけが足せる層。** 博論に要る「独立した寄与」の実体もここになる。

### 山西先生への持って行き方

**dry の設計段階で早めに見てもらう。** 前提の訂正で最も変わったのがここである。
初版は「wet を取ってから持って行く」と書いていたが、指導教員相手にそれは最悪の手順になる。

- 先生は **LINCS の専門家**である。Phase 0 の設計（射影順序の修正、細胞内マッチング、効果量の閾値）を
  先に見てもらえば、**7/29 の交差細胞のような手戻りを事前に潰せる**。
  実際あの設計は Iwata 2017 が既に回避していたもので、着手前に相談していれば避けられた公算が大きい。
- wet に 1〜2ヶ月を投じる前に、**方向性の合意を取る方が圧倒的に安い**。
- 「研究室の枠組みを糖鎖に持ち込み、read-out を増殖でなくレクチンにする」という筋は、
  ラボの路線の延長でありながら学生固有の寄与になる。**指導教員が最も承認しやすい形**でもある。

**Akiyoshi には Phase 0 に入る前に一度話す。** 相談相手であって、競合ではない。

**先に確認すべき事務的な条件**（これを知らずに計画は完成しない）：
論文博士の要件（必要な論文数／1st・2nd が算入されるか）、想定する投稿先、時期。
これらは指導教員が決めるもので、答えによって 3rd paper に必要な射程が変わる。

> ⚠ `docs/yamanishi_collaboration.md` は「共同研究の落とし所メモ」として書かれている。
> 分担イメージの節は外部との交渉を想定した枠なので、**分担でなく
> 「研究室の資産のうち何を借りるか」のリスト**として読み替えること。

## やること（この順で）

### Phase 0：dry の土台を正す（1〜2週）

**0-1. 射影順序の修正を絶対量で実行する。**
現行は `Δ発現 → max/min射影`。律速の min は発現**レベル**に対して定義されているので、正しくは
`処理後レベル→射影` と `対照レベル→射影` を別々に出して差を取る（`docs/negative_result_cross_cell_transfer.md` 末尾）。
必要な絶対量は `data/processed/abs_full_*.npy` に揃っている（118,900試料 × 23,614遺伝子、2026-08-01抽出）。
テンプレートは `notebooks/archive/01_epitope_potential.ipynb`。

**0-2. 出力を「マップ」でなく「候補表」にする。**
HEPG2 単独（PHH を正常対照）に絞り、次の5列だけを出す。

```
薬剤 / エピトープ / 方向 / 効果量 / 対応する認識分子（レクチン・抗体）
```

閾値は統計の p ではなく **AAL フローで検出できるか**という実務側から逆算する
（発現1.5倍以上・複数濃度で単調・6hと24hで同符号、など）。
こうすると「薬剤6.3%」問題にも「31/47エピトープが1遺伝子」問題にも引っかからない——
どちらも**平均と集合検定の話**であって、効果量の裾の話ではないため。

**0-3. wet の標的（細胞株 × エピトープ）を Phase 0 の出力として決める。**

> **訂正（2026-08-02）**：初版はここで「core fucose（FUT8）を第一軸にする」と書いていた。
> **これはHCC時代からの惰性であってデータから導かれたものではなく、実際に確認したらデータは支持しなかった。** 下記参照。

選定基準を先に明文化し、それに照らして決める（`docs/wet_target_selection.md` に詳細）：

1. **薬剤で動く裾があるか** — 平均でなく、効果量の上位に実際に薬があるか。
   **判定は「他の遺伝子より動くか」（順位）ではなく「何本の薬が検出閾値を越えるか」（絶対量）**。
   前者は遺伝子レベルの問いに滑り落ちており、創薬的な意味を持たない
2. **ベースラインが検出可能な水準か** — 発現が無い遺伝子は「下げ」を測れない
3. **検出試薬が枯れているか** — レクチン／既存抗体で、安価に
4. **臨床的な意味があるか** — 承認バイオマーカー・既存標的に接続するか
5. **スコアリング枠組みが働くか** — 単一遺伝子だと max/min が恒等写像になり、本研究の手法的貢献が素通りする
6. **汎ストレスの代理でないか** — 上位が UGT/解糖系で埋まるので、特異性チェックが要る

## 博論としての一本の弧

論文博士は3本の独立した論文ではなく、**貫く一文**が要る。

```
1st  組織の糖鎖遺伝子発現を読む            （静的・組織）
2nd  薬剤で糖鎖遺伝子が動くことを示す      （動的・遺伝子）
3rd  それを認識分子が触る「面」の単位に翻訳し、実測につなぐ （動的・表面表現型）
```

**一文：糖鎖遺伝子の発現を、組織 → 薬剤応答 → 細胞表面の認識インターフェース、と段階的に「測れる標的性」へ翻訳する。**

各段で**測定量が上がっている**（発現 → 発現変化 → 表面エピトープ）のが要点で、
3rd で初めて実測（レクチン）に着地する。この弧があると3本が一つの主張になり、
無いと「同じデータで3回解析した」に見える。**弧を完成させるのも wet である。**

## 捨てるもの・やらないもの

- **汎系統／交差細胞の転用マップ** — 2026-07-29 に不成立確定。しかも Iwata 2017 が既に回避済みの設計。退避済み（`results/_retired/01_cross_lineage/`）。
- **dry の精度勝負** — target repositioning の AUC 0.63〜0.65 が示すのは
  「トランスクリプトームからの予測の天井はこの程度」であり、**研究室自身が精度でなく仮説生成で価値を作っている**。
  ラボの方針に反してまで精度を追う理由がない。手法は house style（細胞内マッチング、経路スコア）に素直に乗せる。
- **MoA/ATC クラス濃縮** — 2nd paper の反省（既知の PXR/CAR 誘導の糖鎖版なぞりで "so what" 止まり）。
- **エピトープ集合の超幾何検定** — 31/47 が1遺伝子で原理的に成立しない（`docs/set_based_aggregation_feasibility.md`）。
- **経路レベルへの降格** — 統計は通るが 2nd paper と重複し、エピトープ解像度という差別化軸を失う。

## 最大のリスク

**wet ができないなら、この計画は根本から組み直しになる。**

wet が使えない場合の代替は、実測された糖鎖データを外部から持ってくること
（CPTAC の糖鎖プロテオミクス、HCC の lectin array 文献、TCGA-LIHC）。
ただし「薬剤で動かした糖鎖の実測」は公開データに存在しないため、
**薬剤誘導という本プロジェクトの中核主張は dry のままでは検証できない**。
その場合は主張を「薬剤誘導」から「糖鎖標的性の記述的地図」に下げることになり、
**Akiyoshi 2020 との距離が縮まる**——同じ研究室の既発表と近い位置に落ちるので、
博論としての独立した寄与を示しにくくなる。

つまり **wet の可否が、この研究の価値の大きさをそのまま決める。** ここを最初に確定させること。
そしてこれは指導教員に相談すべき筆頭事項でもある（実験環境・予算・共同先の手配は
学生一人で決められる話ではない）。
