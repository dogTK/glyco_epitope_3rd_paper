# wet標的（細胞株 × エピトープ）の選定（2026-08-02）

「なぜ HepG2 と core fucose なのか」という問いに答えるため、初めてデータで確認した記録。

**結論：HepG2 は支持される。core fucose は支持されない。**
両者はHCC時代からの惰性で残っていたもので、これまで一度もデータから再導出されていなかった。

> ## ⚠ 初版の方法論的誤り（同日中に訂正）
>
> 初版は **385 glycogene の中での順位**（FUT8は215位）で議論していた。**これは遺伝子の話であって
> エピトープの話ではなく、創薬的な意味を持たない。** 理由は2つ:
>
> 1. **比較相手が不適切**。385 glycogene には UGT・トランスポーター・加水分解酵素など
>    **そもそもエピトープを持たない遺伝子**が多数含まれる。その中での順位に意味はない。
>    実際、上位は UGT2A3・SLC2A3・HK2・SLC2A1（Warburg）で埋まっていた。
> 2. **順位は問いに答えていない**。創薬的な問いは「その薬がエピトープを、
>    **レクチンで見えるだけ**動かすか」であって、他の遺伝子より動くかではない。
>    判定は**絶対的な効果量 vs アッセイの検出閾値**でなければならない。
>
> **なぜこの drift が起きたか（構造的な原因）**：辞書の **31/47 エピトープが単一遺伝子**なので、
> 大半のエピトープでは「エピトープ量＝その遺伝子の値」と数値的に同一になる。
> **だからどの解析も、エピトープ単位のつもりで自然に遺伝子単位へ滑り落ちる。**
> これは今回の解析だけの不注意ではなく、「エピトープ解像度」という売りの弱点そのもの
> （`docs/set_based_aggregation_feasibility.md`）。以下 §3 は正しい単位でやり直したもの。

---

## 1. なぜ惰性なのか（経緯）

```
〜2026-07-27  HCCが論文の背骨。HepG2 + core fucose は必然だった
 2026-07-28  汎系統ピボット。HCCを主役から明示的に降ろす
 2026-07-29  その汎系統マップが実データで死亡
      →      背骨が消えたのに HepG2 + core fucose だけが残った（再導出されていない）
```

`docs/paper_value.md` が HCC を残した理由として挙げているのは **PHH（正常肝細胞）が LINCS 最良の正常対照**という
一点のみで、これは**細胞株の理由であってエピトープの理由ではない**。core fucose 側の根拠は
「AFP-L3 の実体」という臨床的な意味づけだけで、薬剤で動くかは確認されていなかった。

## 2. 確認した内容

`data/processed/abs_glyco_16cell_24h.parquet`（69,918試料 / 16細胞 / 385 glycogene, 24h）で、
各細胞について「薬剤ごとの平均発現 − その細胞の全薬剤中央値」の分布の広がり（sd）を遺伝子ごとに計算した。
＝ **その細胞でその遺伝子が薬剤によってどれだけ振れるか**。

### 2-1. 細胞株レベル：HepG2 は妥当

| 細胞 | 全385遺伝子の sd 中央値 |
|---|---|
| THP1 | 0.511 |
| A549 | 0.414 |
| **HEPG2** | **0.401**（16細胞中 3位） |
| HT29 | 0.400 |
| MCF7 | 0.385 |
| （以下 PC3 0.379 … U2OS 0.280） |

**HepG2 は糖鎖遺伝子が薬剤で動きやすい方の細胞である。** PHH という正常対照が付くことと合わせて、
細胞株の選択は支持される。

### 2-2. ⚠ 以下は誤った単位（遺伝子レベル）の解析。§3 に置き換え済み

HEPG2（24h / 175薬）で、385 glycogene を薬剤誘導スプレッド順に並べたときの位置：

| エピトープ | 遺伝子 | sd | base | 順位 |
|---|---|---|---|---|
| β1,6分岐 | **MGAT5** | **0.65** | 6.1 | **28位** |
| T抗原 | C1GALT1 | 0.48 | 6.6 | 119位 |
| **Core fucose** | **FUT8** | **0.39** | 5.2 | **215位**（中央値以下） |
| Bisecting GlcNAc | MGAT3 | 0.39 | 1.1 | 201位 |
| Lewis y 構成 | FUT6 / FUT4 / FUT1 | 0.46〜0.39 | 2.1〜2.3 | 133〜204位 |
| Lewis y 構成 | FUT2 / FUT3 / FUT9 | 0.30〜0.27 | 1.2〜0.6 | 318〜341位 |
| Sialyl Lewis a (CA19-9) | FUT3 / ST3GAL3 / ST3GAL4 | 0.30〜0.21 | 3.7〜0.6 | 318〜362位 |

**FUT8 は385遺伝子中215位で、中央値を下回る。** HepG2 で core fucose を動かす薬を探すのは、
最も動かない側の遺伝子を選んでいることになる。

さらに16細胞で FUT8 を比較すると、HepG2 は **9位**：

| 細胞 | FUT8 の sd | 薬剤数 |
|---|---|---|
| PC3 | 0.619 | 1,407 |
| YAPC | 0.584 | 868 |
| A549 | 0.525 | 1,138 |
| … | | |
| **HEPG2** | **0.385** | **175** |

core fucose をどうしても主役にするなら **PC3 か A549 の方が、振れ幅で1.4〜1.6倍・薬剤数で6〜8倍**有利。
ただしその場合 PHH の正常対照を失う。

### 2-3. Lewis 系は HepG2 では測れない

FUT3 の base = 0.6、FUT7 = 0.2、ST3GAL3 は 362位。**HepG2 では Lewis 系がほぼ発現していない。**
無いものは減らせないので、Lewis y（7遺伝子）や Sialyl Lewis a（CA19-9）といった
「複数遺伝子でスコアリング枠組みが実際に働く」エピトープは、HepG2 では検証できない。
やるなら大腸（HT29）や膵（YAPC）に移ることになり、PHH を失う。

## 3. 正しい単位でのやり直し：エピトープ × 検出閾値

**問い**：各エピトープを、**何本の薬が検出可能な大きさで動かすか**。
順位でなく絶対量で、閾値はアッセイ側（レクチンフローで見える倍率＝2倍）から決める。
射影の順序も正しい形にした（`レベル→射影→差`）。実装 `scripts/check_epitope_druggability.py`。

※ step間min は Snowflake の `EPITOPE_STEP_GENE` が要るのでここでは**内max のみ**。
  辞書は最大2ステップなので一次近似としては妥当だが、Phase 0 で正式版に差し替えること。

### HEPG2（24h / 175薬 / 52エピトープ）

| エピトープ | 遺伝子数 | base | 2倍以上動かす薬 | 上げ / 下げ | 最大変化 (log2) |
|---|---|---|---|---|---|
| **β1,6分岐 (MGAT5)** | 1 | 6.06 | **22本 (12.6%)** | 3 / 19 | +1.12 / **−1.85** |
| Chondroitin-6-Sulfate | 2 | 4.34 | 18本 (10.3%) | 9 / 9 | +1.42 / −1.76 |
| O-GlcNAc | 1 | 7.80 | 18本 (10.3%) | 1 / 17 | +1.16 / −2.46 |
| GD2 | 1 | 4.15 | 17本 (9.7%) | 4 / 13 | +1.32 / −3.59 |
| T抗原 | 1 | 6.61 | 15本 (8.6%) | 0 / 15 | +0.61 / −1.47 |
| Bisecting GlcNAc (MGAT3) | 1 | 1.07 | 4本 (2.3%) | 3 / 1 | +1.75 / −0.82 |
| **Core fucose (FUT8)** | 1 | 5.17 | **2本 (1.1%)** | — | +0.76 / −1.46 |
| Sialyl Lewis a | 3 | 3.68 | 1本 (0.6%) | | +1.09 / −0.77 |
| Lewis y | 6 | 2.63 | 1本 (0.6%) | | +1.03 / −0.73 |
| Lewis x | 4 | 2.58 | **0本** | | +0.72 / −0.72 |

**core fucose を2倍動かす薬は175本中2本（1.1%）。β1,6分岐は22本（12.6%）で10倍以上の差。**
順位でなく「何本の薬が使えるか」で見ても結論は同じで、しかもこちらは wet の実験計画に直接使える数字である。

### 副産物：アイソ酵素の冗長性が高いエピトープほど薬剤で動かない

多遺伝子エピトープが軒並み下位に来ている（Lewis y 6遺伝子で1本、Lewis x 4遺伝子で0本、
Sialyl Lewis a/x 3〜6遺伝子で1本）。**これは内max射影のアーティファクトではなく、生物学的な予測である。**

内max はアイソ酵素の冗長性（並列OR）を表す。冗長性があるエピトープを下げるには
**薬が全アイソ酵素を同時に抑える**必要があり、それは起きにくい。
逆に単一酵素で決まるエピトープ（MGAT5, FUT8, MGAT3, C1GALT1）は1遺伝子を動かせば動く。

> **「エピトープは、それを作る酵素の冗長性が低いほど薬剤で操作しやすい」**

これは **遺伝子レベルの解析では原理的に言えない、エピトープ単位でしか出てこない主張**であり、
「どのエピトープが薬で狙えるか」を事前に判定する基準になる＝創薬的な意味がある。
Fig3 の軸をこれにすると、単なるヒートマップより主張が立つ。

**ただし代償**：スコアリング枠組み（内max × 間min）が実際に働くのは多遺伝子エピトープだけで、
そこは軒並み動かない。**手法が効く場所と信号がある場所が食い違う**という構造は、
論文で正面から書くべき limitation（§4 と合わせて）。

## 4. core fucose のもう一つの問題：手法が素通りする

core fucose は GlycoEpitope DB に無く、**手動キュレーションで追加したエントリ**（MAN0001）である
（`docs/epitope_supplement_rationale.md`）。FUT8 はヒトで唯一の core フコース転移酵素なので、
**このエピトープは定義上1遺伝子**。

したがって GlycoMaple ロジック（step内max × step間min）は**恒等写像になる**。
`docs/paper_value.md` は「素朴な和でなく生合成経路を反映したスコアだからこそ価値がある」と書いているが、
**その価値を検証する場として core fucose を選ぶと、手法は一切テストされない**。
wet が示すのは「FUT8 の mRNA が上がると AAL 反応性が上がる」——正しいが教科書的で、本研究の方法論的貢献とは無関係。

補完根拠のドキュメントは単一遺伝子であることを「スコアリングにむしろ最適」と書いている。
クリーンさの意味ではその通りだが、**手法の実証という観点では逆に働く**。

## 4. 現時点での推奨

**HepG2 は維持し、エピトープを MGAT5（β1,6分岐）に寄せて再検討する。**

- 28位 / sd 0.65 で、HepG2 で実際に薬剤に動く
- base 6.1 と十分発現しており、**増加も減少も測れる**
- **L-PHA** という確立した検出レクチン（AAL/LCA と同程度に枯れている）
- 転移・galectin-3 リガンド化という生物学があり、Fig5 の galectin 軸の起点
- **MGAT3（bisecting）と生合成的に拮抗する**ので、「片方を上げる薬は他方を下げるか」という
  分岐競合（v3設計）の検証にもなり、単一遺伝子より手法的な中身がある
- HepG2 vs PHH で **MGAT5 +2.48** と既に大きな差が確認済み（`results/tables/hepg2_vs_phh_glycogene_delta.csv`）

core fucose は**捨てずに第2軸に残す**。AFP-L3 という臨床的な錨は強く、
AAL は安価なので、同じ細胞・同じ薬で同時に染めればコストはほぼ増えない。
「動くと予測した MGAT5 は動き、動かないと予測した FUT8 は動かない」という
**陰性対照込みの図**にできれば、単独で主張するより強い。

## 5. この確認の限界

- 対照を引いていない（細胞内の中央値からのズレで代用）。**射影順序の修正（Phase 0-1）後にやり直す必要がある。**
- 上位は UGT2A3・SLC2A3・HK2・SLC2A1（Warburg）など**代謝・ストレス系が占める**。
  MGAT5 の 28位 も汎ストレスの巻き添えでないかを、特異性チェックで潰す必要がある。
- HepG2 の 24h は 175薬しかない。**HepG2 の主力は 6h（590薬）** なので、6h でも同じ順位になるか要確認。
- 「発現が動く」と「糖鎖が動く」は別（局在 GALA・翻訳後制御）。それを確かめるのが wet の役目。
