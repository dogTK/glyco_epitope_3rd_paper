# 否定的結果：交差細胞の epitope 転用可能性は成立しない（2026-07-28/29）

Fig4として設計した「系統横断 epitope 転用可能性マップ」を実データで検証し、**成立しないと判定した**。
同じ設計を再発明しないための記録。実装は `notebooks/analytics/01_cross_lineage_epitope_transferability.ipynb`。

## 何を主張しようとしたか

`d(薬X@系統a, 薬Y@系統b) < d(薬X@系統a, 薬X@系統b)`
＝「肝でX薬が作る糖鎖状態は、肺ではY薬が作る」→ 検出試薬・抗体・ADCが系統を越えて転用できる。

## 検証で潰れた経緯

| 施策 | 結果 |
|---|---|
| 初回（用量・時間を混合して平均） | ランダム推論遺伝子セット対照 **perm p = 0.935**。同一薬より近い異薬ペアが38.8%、入れ替え相手を持つ薬が99.3%で主張が空洞 |
| 用量・時間を 10 µM/6 h に固定 | **p = 0.796**。回復せず（LINCS Level 5 は既にレプリケート統合済みで、1行=(薬,細胞,用量,時間)。当初の「split-half再現性0.24」は複製でなく異条件間を測っていた） |
| 射影後センタリング | 異薬 cos が +0.151 → **−0.002** と正常化。ただし同一薬との**差は +0.039 → +0.038 で不変**。オフセットは見栄えの問題で、信号不足の原因ではなかった |
| シグネチャ強度フィルタ（top20%/10%） | 差 +0.053 / +0.061 まで微増。逆転率は38〜42%から下がらず |
| 細胞内センタリングの除去 | 差 +0.043 → +0.052。Level 5 は population control 済みなので二重除去だった。是正して僅かに改善 |
| Spearman（行内ランク） | 差 **−0.005**、逆転51.1%＝完全にランダム |

## 決定的な数字：nullのプールを3群にして比較

当初のnullは `GLYCO_GENES_WIDE` から引いていたため**プールが全てglycogene**で、
「エピトープ遺伝子はglycogeneの中で特別か」しか検定できず循環していた。
**実測ランドマークをプールに加えて**初めて原因が確定した。

```
56遺伝子, 強度top20%, 10 µM/6 h, HEPG2 × A549   （同一薬 vs 異薬 の差）

エピトープ辞書（推論56）        +0.0092
ランダム推論glycogene 56        +0.0148   [90%区間 −0.036 〜 +0.060]
ランダム実測ランドマーク 56      +0.2088   [90%区間 +0.140 〜 +0.271]

perm p vs 推論glycogene        0.562
perm p vs 実測ランドマーク      1.000    ← 200セット全てに負け
```

## 結論と原因

1. **実測か推論かの一点で決まっている。**
   - 遺伝子の選び方の問題ではない：ランダムな56遺伝子でも実測なら +0.21 出る
   - 遺伝子数の問題でもない：959全部（+0.191）とランダム56（+0.209）がほぼ同じ
   - L1000の推論モデルは**細胞株ごとに学習されている**ため、推論値には細胞を跨いで転移する
     薬剤情報が原理的に乗らない
   - エピトープ辞書57遺伝子中、実測ランドマークは **3個のみ（EXT1, FUT1, ST3GAL5）**
   → **この設計では交差細胞の議論は原理的に不可能。**
2. **副次的に：エピトープ射影後に見える +0.05 は人工物**（主因ではない）。max→min の順序統計が
   薬剤の応答強度に依存するため、強い薬は全エピトープが揃って同方向にずれる。「強い薬はどの細胞でも
   強い」ので、この共通方向が同一薬類似度として計上される。糖鎖パターンでなくスカラーの薬剤強度が
   漏れている。裏付け：行方向センタリングに相当するSpearmanでこの成分を除くと残りはゼロになる。

## 何が無傷か

**Fig1〜3（細胞内の drug → epitope）は影響を受けない。** 交差細胞の転移を前提としていないため。
壊れたのは「系統を跨ぐ」主張のみ。

## 派生して見つかった設計上の誤り（Fig1〜3にも効く・要修正）

**律速ロジック（step間min）は発現「レベル」に対して定義されているのに、我々は「変化量Δ(z-score)」に適用している。**

- 本来の意味：経路は最も低い酵素で頭打ち（直列AND）。step内maxはアイソ酵素の冗長性（並列OR）。
- Δにminを掛けると「最も**下がった**ステップ」を拾うが、それは律速ステップではない。
  大きく下がっても元が潤沢なら律速でないし、ほとんど動かなくても元から低ければそこが律速。
- これが上記の人工物の発生源でもある。Δのminは最も負の値なので、応答が強い薬ほど大きく振れ、
  スカラーの薬剤強度が漏れる。

**正しい順序**（射影は非線形なので「先に引く」と「後で引く」は一致しない）：

```
現行（誤）: Δ発現 → max/min射影 → Δエピトープ
正しい形  : 処理後レベル → 射影 → エピトープ量(処理後)
            対照レベル   → 射影 → エピトープ量(対照)
            差を取る    → Δエピトープ
```

絶対量データは `RAW.LINCS.CTL_GLYCO_GENES_WIDE` / `CTL_PREDICTED_RNASEQ_LONG` にある。
**交差細胞の否定的結果とは独立の問題で、生き残っている Fig1〜3 に効くため修正の価値がある。**

## 再挑戦するなら
