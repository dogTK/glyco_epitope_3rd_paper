# 集合ベース集約（上位下位5%＋超幾何）の実現可能性（2026-07-29）

山西研（Iwata 2017）の集合ベース集約を自分の糖鎖スコアに輸入できるか、実データで検証した記録。

**結論：経路レベルでは可能（65経路）。しかしエピトープレベルでは統計的に不可能。**
これは Fig 1〜3 の「エピトープ解像度」という売りに直接効く。

---

## 1. 検証した問い

> GlycoEnzOnto の経路に対して、各シグネチャの上位5%/下位5%遺伝子と超幾何検定をやる。
> それを Fig 1〜3 の作り直しに使えるか。

---

## 2. エピトープレベル：不可能

`RAW.GLYCOEPITOPE.VW_EPITOPE_GLYCOGENE` の 59 エピトープを L1000 遺伝子空間と交差させた結果。

| L1000内の遺伝子数 | エピトープ数 |
|---|---|
| 0（検定不能） | 12 |
| **1** | **31** |
| 2–4 | 15 |
| 5 | 1（Lewis y のみ） |

### なぜ致命的か

超幾何検定の**最良ケース**（集合の全遺伝子が5%裾に入った場合）の p 値は、
universe N=12,328・裾 K=616 で次の通り：

| 集合サイズ n | 到達しうる最小 p |
|---|---|
| 1 | **0.050** |
| 2 | 0.0025 |
| 3 | 1.2e-4 |
| 4 | 6.2e-6 |
| 5 | 3.1e-7 |

- **1遺伝子エピトープ（31/47）は、どんなに強い薬剤応答でも p < 0.05 に到達できない。**
  多重比較補正を掛ければ全滅する。
- 最大の Lewis y ですら 5 遺伝子で、4/5 が裾に入って初めて p<1e-3。
- つまり「エピトープ集合に超幾何」は、**データが足りないのではなく検定として成立しない**。

### GlycoMaple ロジック（v2: 内max×間min）も同様に効かない

`RAW.GLYCOEPITOPE.EPITOPE_STEP_GENE` は 52 エピトープ / **最大2ステップ** / 98 行。
31 エピトープは「1ステップ・1遺伝子」なので、内max も 間min も恒等写像になる。
**辞書の3分の2で、v2 のスコアは単一遺伝子の z 値そのもの。**

## 3. 経路レベル：可能（ただし要キュレーション）

`GlycoEnzOnto.gmt` 122経路。L1000 と交差した後：

- 1遺伝子以上を含む経路：**109**
- 遺伝子集合が完全一致する経路をまとめた後の代表：**103**
- **採用可能（5≤n≤100 かつ代表）：65 経路**

### 冗長性が強い（キュレーション必須）

サイズ5–100の68経路について：

- 完全包含ペア 108 / 2278 ペア
- Jaccard ≥ 0.5 のペア 48
- **遺伝子集合が完全一致（J=1.00）のペアが3組** — 名前だけ違う同一集合。
  そのまま検定すると FDR で二重計上され、1件のヒットが2件に見える。
  - `heparan sulfate degradation` = `heparan sulfate lysosome degradation`（各8遺伝子）
  - `glycan donor transport` = `nucleotide sugar transport`（各6）
  - `glucose transport` = `monosaccharide transport`（各7）
- 他経路の真部分集合でない経路は **12個しかない** ＝ 階層がほぼ入れ子。
  「独立な65経路」ではなく「入れ子の65経路」であることを明記して扱う必要がある。

### 検出に必要な裾遺伝子数（p<1e-3 目安）

| 経路サイズ | 必要な裾遺伝子数 |
|---|---|
| 5 | 4/5 |
| 6 | 4/6 |
| 8 | 4/8 |
| 10 | 5/10 |
| 15 | 5/15 |
| 25 | 7/25 |
| 38 | 8/38 |

小さい経路ほど「ほぼ全部が裾」を要求される。実質的に効くのは 10 遺伝子以上の経路。

## 4. 今回 Snowflake に載せたもの

`RAW.LINCS.GLYCOENZONTO_PATHWAY_GENE`（1,471行 / 109経路）

| カラム | 意味 |
|---|---|
| `PATHWAY_NAME` / `PATHWAY_DESC` | GlycoEnzOnto 経路名と定義文 |
| `N_GENE_L1000` / `N_GENE_TOTAL` | L1000内の遺伝子数 / 経路の総遺伝子数 |
| `GENE_SYMBOL` / `GENE_CLASS` | landmark / best_inferred / inferred |
| `IS_REPRESENTATIVE` / `REPRESENTATIVE_OF` | 同一遺伝子集合の重複除去用 |
| `IS_SUBSET_OF_OTHER` | 他経路の真部分集合か（入れ子フラグ） |
| `IS_USABLE_SET` | 5≤n≤100 かつ代表 → **65経路** |

出典: Groth et al., Bioinformatics 2022（CC-BY-4.0、帰属必須）。

## 5. 未決の分岐

集合ベース集約は経路レベルでしか成立しないため、Fig 1〜3 の単位を決め直す必要がある。

- **A. 経路レベルに降りる** — 統計的に正当だが、エピトープ解像度（差別化3軸の1つ）を失う。
  経路→エピトープは注釈レイヤーに格下げ。
- **B. エピトープレベルを維持し、超幾何をやめる** — 1〜5遺伝子の連続スコア＋置換検定で null を作る。
  31エピトープでは「スコア＝単一遺伝子の z 値」であることを論文中で明示する。
- **C. 併用** — 統計の主張は経路レベル、解釈レイヤーはエピトープレベル。
