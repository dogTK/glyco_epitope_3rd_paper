# 方針転換: signature-reversal を捨て、targetability へ（2026-07-25）

本プロジェクトの土台となる方針転換の記録。**「がんシグネチャーを正常へ逆位させる薬を探す」枠を放棄し、
「測れる糖鎖表面表現型を薬で動かす（targetability）」枠に完全にピボットする。**

## なぜ reversal 枠を捨てるか（3つの批判）

signature-reversal-to-normal（薬でがん状態を正常へ戻す）は、以下の理由で前提が壊れている。

1. **経験的**：逆位リポジショニングは承認薬でも綺麗に効かず取りこぼす。
   - 実測: 承認薬-疾患 recovery AUROC は transcriptome 0.50 / glycogene 0.45 / epitope 0.52 とほぼランダム（notebooks/reproduction/04）。
   - HCC-正常 reversal の構造化は全tx/glyco/epitope すべて perm_p=0.002 で**糖鎖固有でない**し、承認薬は集団として正常化に偏らない（むしろ微増幅, p=0.014）。
2. **概念的**：`正常` だけが良い状態ではない。薬はがん細胞を**別の安定状態（アトラクタ）へ横に再配置**しうる。
   正常軸への射影しか見ないと、この "横に逃げる" 変化を丸ごと見落とす。
3. **機序的（本質）**：正常→がん の進展は分化のように**一度進むと状態が固定される（Waddington地形／カナリゼーション）**。
   小分子の発現摂動では谷を登って元へ戻れない。戻すには TF強制発現・エピゲノムリセット＝iPS初期化級のダイナミクスが要る。
   - 経験的裏づけ: 「発現シグネチャーを正常へ逆転させて奏効」した臨床例はほぼ APL の ATRA（分化誘導）のみ。例外が原則を証明する。

→ **「がんシグネチャーを正常へ戻す薬を探す」は生物学的に無理を抱えた枠**。手法でなく問いの前提が壊れている。

## なぜ targetability は生き残るか（決定的な区別）

上の3批判は**すべて「細胞"状態"を正常へ戻す」を撃っている**。しかし本研究の狙いは状態逆転を要求しない。

- ❌ **細胞を正常化する** = アトラクタ脱出 = reprogramming級 = 無理
- ✅ **細胞表面の1つの測れる特徴（例 core fucose）を、検出/標的に足る分だけ動かす** = 局所のノブ、状態遷移不要

**アトラクタの議論は「1個の表面ノブ」には効かない。** がんはがんのまま、でも core fucose が下がれば AFP-L3 は下がり、
抗体/レクチンの標的密度・検出性は変わる。「正常に戻す」を諦め「測れる標的を動かす」に降りれば、3つの批判は全て回避できる。

## 新しい問いの立て方

- 予測（正しい逆位薬を当てる、精度勝負）を**やめる** → シグナルが弱くrecallが立たない土俵。
- 抽象シグネチャーへの逆位を**やめる** → "どのシグネチャーが正解か" 問題・アトラクタ問題を回避。
- **測れる糖鎖表現型（glyco-epitope）を錨にする** → core fucose/分岐/STn等、レクチン・抗体で実測でき生物学的意味がある1軸。
- **記述に徹する** → 「薬が糖鎖インターフェースに何をするか」の状態マップを描き、標的性・検出性が高い領域を示す。
- **正常かどうかは問わない** → 薬が誘導する glyco-phenotype の状態空間として扱う。

## 論文への効かせ方

- **Introduction/Discussion の骨**：「なぜ固形がんで reversal-repositioning が効かないか（アトラクタ論）→ だから状態でなく表面表現型に錨を打つ」。批判自体が差別化になる。
- **主張する**：薬が測れる糖鎖標的（core fucose/AFP-L3 等）を動かしうる＝標的性・検出性の再配線。候補を出せる。
- **主張しない**：薬ががんを正常化・治癒する（状態逆転）。
- **勝ち筋**：wet validation（HepG2 + AAL/LCA で予測通り core fucose が動く）。dry は候補生成と解釈に徹する。
