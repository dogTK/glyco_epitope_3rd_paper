**2.1. がんにおいて特異的に発現する糖鎖**

- がんの異常糖鎖付加は腫瘍関連糖鎖を生み、発症・進展を支える。内訳は大きく4つ：
	- **短縮O型糖鎖**（Tn、STn、T抗原）
	- **N型糖鎖のβ1,6分岐の増加**
	- **末端シアリル化**（ポリシアル酸を含む）
	- **コア／アンテナのフコシル化** → 結果として細胞表面に **sialyl Lewis x / sialyl Lewis a** が濃縮
- これらは細胞表面に留まらず分泌・血中放出もされ、そのまま臨床バイオマーカーになっている：SLea=**CA19-9**、STn=**CA72-4**、MUC16=**CA125**、MUC1=**CA15-3**
- がんでの発現が高度に限局しているため、標的治療のターゲットとして有望——というのが本レビューの出発点

**自分の辞書での GD2 はどうなっているか**

GD2 は **EP0061**、末端酵素は **B4GALNT1 の1遺伝子・1ステップだけ**（`data/processed/epitope_step_gene.csv`、pathway は ganglioside core structure biosynthetic pathway）。単一遺伝子なので内max×間min が恒等写像になり、GlycoMapleロジックが何も仕事をしない典型例。

上流拡張後（`epitope_step_gene_expanded.csv`）は21遺伝子：

| 深さ | 遺伝子 |
|---|---|
| 0（末端） | B4GALNT1 |
| 1 | A4GALT, B3GALNT1, B3GNT5, **B4GALT6**, **ST3GAL5**, **ST8SIA1**, ST8SIA5 |
| 2 | B3GALT4, B3GALT5, GAL3ST1, ST3GAL2, **UGCG**, UGT8 |
| 3 | C1GALT1, GALC, GBA, GBA2, GBA3, ST6GALNAC5, ST6GALNAC6 |

太字が既知経路 **UGCG→B4GALT6→ST3GAL5→ST8SIA1→B4GALNT1** で、DAG構築の検証はこれが正しく復元されることで通した。ただし DAG なので globo系（A4GALT）・lacto系（B3GNT5）や分解酵素（GALC/GBA）も同じ袋に入っている。

- GD2 と N-Acetyl GM2 はどちらも B4GALNT1 だけで**辞書上区別できない**（重複エピトープとして代表に畳み込み、52→39件）
- 最終版（案D＝末端の値×上流ゲート）では **HEPG2 で GD2 はゲート落ち**（`epitope_druggability_hepg2_gated.csv` に行がない）。基質を作れない＝神経外胚葉系抗原を肝細胞株が作らない、で生物学的に正しい。案A（末端のみ）時代は175薬中32本が2倍超（18.3%）で「ドキソルビシンがGD2を1/8にする」が最大の所見だったが、アーティファクトとして消滅
- **唯一承認薬がある糖鎖エピトープが、HEPG2 解析では見えない**という位置関係。GD2 を扱うならメラノーマの A375（旧テーブルで n2x=41）が候補
