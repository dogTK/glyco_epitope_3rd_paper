# エピトープ生成ロジック（epitope potential の計算）

## 一言でいうと

**「その糖鎖エピトープを作る酵素たちが、どれだけ働いているか」から、
エピトープが細胞表面にどれだけ出ているかを見積もる。**

ただし単純な足し算ではなく、**冗長性（予備の酵素）と律速（ボトルネック）を区別する**のが肝。

---

## なぜ足し算ではだめか

エピトープは「工場の製品」だと思うとよい。

- **同じ工程を担う予備の機械が複数ある**（アイソ酵素）→ 1台止まっても他が回るので、**一番よく動いている台**を見る
- **工程が順番に並んでいる**（生合成の各ステップ）→ **一番弱い工程**で全体が頭打ちになる

足し算だとこの2つを区別できない。予備が3台あるのと、3工程が全部必要なのとでは、意味が正反対になる。

---

## 2つのルール

出典は **GlycoMaple**（Huang et al., Dev Cell 2021）の集約ロジック。

```
ステップ内（アイソ酵素）  → max   … 並列 OR。どれか1つ働けばよい
ステップ間（逐次の工程）  → min   … 直列 AND。全部揃わないと進まない
```

式で書くと、エピトープ e の量は

```
ステップ活性  A_s = max( ステップ s に属する酵素の発現 )
エピトープ量  P_e = min( A_1, A_2, ..., A_S )
```

### 直感の確認

- **Lewis y** には FUT1/2/3/4/5/6/9 の**7遺伝子**が登録されているが、EC番号を見ると 2.4.1.152 が繰り返されている。
  つまり**7個は全部「同じ工程の予備」**。→ max を取る。だから1個くらい薬で下がっても Lewis y は減らない。
  実際、薬で Lewis y が2倍動く例は HepG2 で **0本**だった。
- 逆に **単一酵素で決まるエピトープ**（MGAT5 の β1,6分岐、FUT8 のコアフコース）は、
  その1遺伝子が動けばエピトープも動く。→ 薬で操作しやすい。

> **エピトープは、それを作る酵素の冗長性が低いほど薬剤で操作しやすい。**
> これは遺伝子レベルの解析では出てこない、エピトープ単位でしか言えない話。

---

## 辞書は「最後の一手」しか持っていない

ここが2026-08-02に判明した重要な点。

エピトープ辞書の出典 **GlycoEpitope DB** は「抗体・レクチンが認識する**決定基**のカタログ」なので、
**その決定基を作る最終反応の酵素だけ**を載せている。

| エピトープ | 辞書が持つ酵素 | 実際に必要な段階 |
|---|---|---|
| **GD2** | **B4GALNT1 のみ** | Cer → UGCG → B4GALT6 → ST3GAL5 → ST8SIA1 → B4GALNT1 の**5段階** |
| T抗原 | C1GALT1 のみ | GALNT族で Tn を作ってから C1GALT1（+ COSMC） |

結果、**52エピトープ中44が「1ステップ」**になっていた。
ステップが1つしかなければ `min` は取りようがない——**律速のロジックが空回りしていた。**

---

## 上流をどう繋いだか（酵素DAG）

GlycoEnzOnto の酵素表には **Reactant（基質）→ Product（生成物）が糖鎖構造の文字列で**入っている。

```
UGCG      : Cer                        → Glc(b1-?)Cer
B4GALT6   : Glc(b1-?)Cer               → Gal(b1-4)Glc(b1-?)Cer
ST3GAL5   : Gal(b1-4)Glc(b1-?)Cer      → Neu5Ac(a2-3)Gal(b1-4)Glc(b1-?)Cer   … GM3
ST8SIA1   : GM3                        → GD3
B4GALNT1  : GD3                        → GD2
```

**「Aの生成物の中に、Bの基質が現れる」なら A → B** と辺を張ると、酵素の前後関係のグラフができる
（353酵素・6,597辺）。B4GALNT1 から遡ると B4GALT6・ST3GAL5・ST8SIA1 が深さ1、UGCG が深さ2 で出てくる。
**教科書通りのガングリオシド経路を、何も教えずに復元できた。**

---

## ところが、上流を min に入れてはいけなかった

上流を足して min を取り直したら、**信号が消えた**（GD2 は 32薬 → 4薬）。

原因：**生の発現量に min を掛けると、「どちらの酵素がたまたま多く発現しているか」で律速が決まってしまう。**
UGCG がいつも低ければ、末端の B4GALNT1 が何倍動いても min は UGCG に固定され、変化が 0 になる。

しかし **発現量の絶対値は酵素間で比較できない**。kcat も基質親和性も基質プールも違う。
GlycoMaple が min を使うのは**複合体のサブユニット間**——化学量論で量が比較できる場合であって、
逐次的に働く別種の酵素に当てはめるのは前提を外れている。

---

## いま採っている形（案D：上流はゲート）

4案を**分割再現性**（同じ薬の試料を半分に割った2本の一致度 vs 別の薬同士）で比べて決めた。

| 案 | 中身 | 再現性の差 | 判定 |
|---|---|---|---|
| A | 末端のみ | 0.497 | 上流を使えていない |
| B | 上流あり × 生の発現量 | 0.504 | ✗ 律速が発現量の大小に乗っ取られる |
| C | 上流あり × 遺伝子ごとに中心化 | 0.406 | ✗ 別の薬同士まで似てしまう |
| **D** | **末端の値 × 上流ゲート** | **0.525** | **採用** |

**案D の考え方**：

- **値**は末端酵素で決める（＝どのエピトープか、の特異性はここが担う）
- **上流**は min に入れず、**「基質があるか」の門**としてだけ使う。
  上流の発現が低すぎる細胞では「そのエピトープは作れない」と判定して無効にする

```
エピトープ量 = max( 末端酵素の発現 )        ただし上流ゲートを通る場合のみ
```

### ゲートが正しく効いている証拠

HepG2 でゲートに落ちたのは 39中5件で、その中に **GD2** が入っていた。
**GD2 は神経外胚葉系（神経芽腫・メラノーマ）の抗原で、肝細胞は作らない。**
辞書には何も教えていないのに、ゲートがこれを再現した。

逆に言うと、ゲート導入前は「ドキソルビシンが GD2 を1/8にする」という所見が図の一番目立つ場所にあったが、
**作れないエピトープの増減を数えていた**ので無意味だった。閾値超えの組は 551 → 396 に減り、
減った分はアーティファクトだった。

## 射影の順序（ここも直した）

`min`／`max` は**非線形**なので、「先に引き算する」と「後で引き算する」で答えが変わる。

```
誤: Δ発現 → max/min → Δエピトープ
正: 処理後レベル → max/min → エピトープ量（処理後）
    対照レベル   → max/min → エピトープ量（対照）
    差を取る    → Δエピトープ
```

律速の `min` は発現**レベル**に対して定義されている。変化量 Δ に min を掛けると
「最も**下がった**ステップ」を拾うが、それは律速ステップではない
（大きく下がっても元が潤沢なら律速でないし、ほとんど動かなくても元から低ければそこが律速）。

**実際に何が変わったか**：単一遺伝子・単一ステップの44件は相関 r = 1.000 で不変（射影が恒等写像なので当然）。
複数遺伝子の8件では r 中央値 0.750、Sialyl Lewis x では **r = −0.193 と逆相関**。
そして**誤った順序は多遺伝子エピトープに偽の応答を作っていた**——Lewis x は正しくは 0本なのに 23本、
Lewis y は 0本なのに 32本と出ていた。

## 限界（論文の limitation に書く）

1. **発現 ≠ エピトープ量。** 酵素の局在変化（GALA）・翻訳後制御で乖離する。
   → **これを確かめるのが wet（レクチン染色）の役目。**
2. **47エピトープ中31が単一遺伝子。** そこでは max も min も恒等写像で、
   スコアは実質その遺伝子の発現値そのもの。「経路構造を反映したスコア」という売りが働かない。
3. **ゲートの閾値は暫定**（上流ステップの最大発現がパネル中央値以上）。感度分析が要る。
4. **測定区分**：辞書57遺伝子のうち L1000 の実測（landmark）は3個だけ（EXT1, FUT1, ST3GAL5）。
   MGAT5 は plain inferred で、値はモデルによる再構成。
