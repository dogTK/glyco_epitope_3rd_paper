## 調査結果

**糖鎖が自己抗原になる病気**

| 疾患 | 狙われる糖鎖・糖鎖エピトープ | ポイント |
| --------------------- | ---------------------------------------- | ----------------------------------------------- |
| **GBS** | GM1, GD1a, GQ1b, GT1a などganglioside | 感染微生物の糖鎖とのmolecular mimicryで自己ganglioside抗体ができる |
| **Miller Fisher症候群** | **GQ1b** | anti-GQ1bが非常に有名 |
| **多巣性運動ニューロパチー（MMN）** | **GM1** | anti-GM1 IgMが代表的 |
| **CANOMAD** | GD1b, GD3, GT1b, GQ1bなどdisialosyl glycan | IgM抗糖脂質抗体による末梢神経障害 |
| **抗MAGニューロパチー** | **HNK-1 carbohydrate epitope** | MAGというタンパク質そのものより、そこにある糖鎖エピトープを抗体が認識 |
| **発作性寒冷ヘモグロビン尿症** | **P antigen** | 赤血球上のglycosphingolipid由来糖鎖抗原に自己抗体 |
| **寒冷凝集素症** | **I / i carbohydrate antigen** | 赤血球表面の糖鎖エピトープにIgMが結合 |
| **IgA腎症** | **galactose-deficient IgA1** のO型糖鎖 | 異常糖鎖によって露出したGalNAc系glyco-epitopeが自己抗体の標的になる |
